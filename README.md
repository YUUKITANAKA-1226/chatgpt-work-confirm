# ChatGPT Work 送信確認

ChatGPTのWorkモードで、うっかりメッセージを送信することを防ぐChrome／Edge向け拡張機能です。送信前に確認ダイアログを表示し、ユーザーがOKを選んだ場合に送信を続けます。

## できること

- Workモードの送信ボタンクリック・Enter送信で確認を表示する。
- キャンセルした場合は送信を止め、入力した文章を残す。
- 通常のChatモードでは確認を出さない。
- Shift+Enterによる改行や日本語IME変換中のEnterには介入しない。

メッセージの保存・外部への転送は行いません。設定画面はなく、読み込むと動作します。

## インストール

1. このリポジトリをダウンロードする。
2. Chromeで `chrome://extensions`、Edgeで `edge://extensions` を開く。
3. 「デベロッパーモード」を有効にする。
4. 「パッケージ化されていない拡張機能を読み込む」を選ぶ。
5. ダウンロードした中の **`chatgpt-work-confirm` フォルダ** を指定する。
6. 開いているChatGPTタブを再読み込みする。

拡張機能を使うだけならNode.jsやChromiumの別途インストールは不要です。普段のブラウザでログイン済みのChatGPTを利用できます。

### 補足：このインストール手順になる理由

ブラウザ拡張機能にも、VS Codeの `.vsix` に相当する `.crx` というパッケージ形式があります。ただし、WindowsのChromeではストア外のCRXのインストールが制限されており、開発者モードを有効にするだけで自由に追加できるわけではありません。[Chrome公式の配布方法](https://developer.chrome.com/docs/extensions/how-to/distribute)

このツールはストアで公開していないため、ChromeとEdgeで共通して使える方法として、開発者モードで拡張機能のフォルダを直接読み込む手順を案内しています。フォルダ内の `manifest.json` が拡張機能の定義なので、リポジトリ全体ではなく `chatgpt-work-confirm` フォルダを指定します。

## 使い方

Workモードで文章を入力し、送信ボタンまたはEnterで送信すると確認が表示されます。

- **OK**：送信を続ける。
- **キャンセル**：送信を止め、入力内容を残す。

導入後は、まずテスト用の文章でキャンセルが機能することを確認してください。更新した際は拡張機能一覧で拡張機能を再読み込みし、ChatGPTタブも再読み込みします。無効化・削除はブラウザの拡張機能一覧から行えます。

## 対応範囲と制限

対象は `https://chatgpt.com/*` です。現在の実装は、日本語UIの入力欄・送信ボタンなどのDOM属性を使ってWorkを判定します。判定できない画面では確認を表示しません。ChatGPT側の画面変更や他言語UI、音声機能、別の送信経路まで保護するものではありません。

ユーザー環境でChromiumの模擬ページテストと実サイトでの動作確認が報告されています。詳細と未確認項目は[検証記録](docs/test-results.md)を参照してください。

## 現時点の課題

- **開発者モードの警告が煩わしい。** 手動で読み込む方式では、利用中もブラウザから開発者モードの無効化を促されることがあり、ユーザー環境のEdgeでもこの案内が残る点が負担になっています。手軽な補助ツールとして使いたいのに、ブラウザ側の警告が日常利用の邪魔になることが課題です。
- **代替の導入方法にも手間がある。** この規模のツールのためにストア登録・審査・公開後の管理まで行うのは負担が大きく、現時点では予定していません。Tampermonkeyで動かす案もありますが、別の外部ツールの導入・設定・管理への依存が増えるため、現時点では採用していません。

警告の煩わしさを避けつつ、外部ツールに依存せず簡単に導入・利用できる配布方法は未解決です。

## 開発・テスト

Node.js 22以上を使用し、リポジトリのルートで実行します。

```powershell
# 単体テスト（依存パッケージのインストール不要）
npm.cmd test

# ブラウザテストの準備と実行
npm.cmd install
npx.cmd playwright install chromium
npm.cmd run test:browser
```

ブラウザテストは模擬ページで実施し、ChatGPTへ実メッセージを送信しません。実サイトで試す場合は、上記の手順で普段のChrome／Edgeに拡張機能を読み込めます。専用Chromiumを起動する `npm.cmd run browser:login` もありますが、今回のユーザー環境ではGoogle経由のログインを完了できませんでした。
